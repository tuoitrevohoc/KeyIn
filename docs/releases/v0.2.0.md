First downloadable **experimental** KeyIn release: an on-device macOS input method for English, Vietnamese Telex, and Simplified Chinese Pinyin.

### Download
- **KeyIn-0.2.0-macos-arm64.zip** — Apple Silicon, **macOS 27.0 or later**. Includes the app, installation instructions and license texts. Bundles Rime and its runtime dependencies; Homebrew is not required to run it.
- **SHA256SUMS.txt** — checksum for the ZIP.
- **keyin-demo.gif** — animated examples, also embedded in the README. This records actual controller/Rime output in a demo layout, not a screen recording of TextEdit.
- Source archives below correspond to tag `v0.2.0`.

### Included
- Rust Telex and language detection, English/Vietnamese typo correction.
- Rime Chinese candidates, sentence composition, contextual initial abbreviations and optional local learning.
- Per-word language selection with Up/Down in Auto mode.
- A simple monochrome vector K icon for the input menu.

### Install
Extract the ZIP and read `INSTALL.txt`. Switch to ABC before replacing an existing installation. Copy `KeyIn.app` to `~/Library/Input Methods/`, log out/in, then add and select KeyIn in Keyboard settings. Back up any previous app first.

### Known limitations
This is a **pre-release**, not a production-ready or notarized distribution. The app is ad hoc signed; macOS may block it. It has no Developer ID signature, notarization, automatic updater, Intel binary or support for macOS earlier than 27.0.

The status panel can remain visible at a screen corner when caret coordinates are unavailable; this issue is **not fixed in this release**. Switch to ABC and quit KeyIn in Activity Monitor to dismiss it, then select KeyIn again. Auto detection is heuristic, and Command-Space conflicts with Spotlight unless reassigned.

### Validation
15 Rust unit tests, Clippy with warnings denied, native Rime/controller smoke tests, dependency isolation and app signature verification. These checks do not establish compatibility with every macOS application.

KeyIn is LGPL-3.0-or-later; dictionary and dependency license notices are included in source and the app bundle.
